# execution-plan

## When to use

Use once scope is understood and work is ready to begin.

## Workflow

1. Order investigation before modification and cheap checks before expensive checks.
2. Define checkpoints, rollback points, and stop conditions.
3. Include validation after each risky step.

## Output contract

A stepwise plan with validation gates.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
