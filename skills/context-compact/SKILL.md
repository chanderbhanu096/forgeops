# context-compact

## When to use

Use when a conversation, task history, or notes are becoming large.

## Workflow

1. Keep goals, hard constraints, decisions, current state, blockers, and next actions.
2. Remove repetition, abandoned branches, pleasantries, and low-value detail.
3. Preserve exact identifiers, commands, paths, numbers, and preferences that affect future work.

## Output contract

A compact continuation brief that can replace the larger context.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
