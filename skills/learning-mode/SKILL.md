# learning-mode

## When to use

Use when the goal is durable understanding rather than just an answer.

## Workflow

1. Start with the mental model and essential vocabulary.
2. Build from a simple example to a realistic example, then edge cases.
3. Use short recall or application checks before adding complexity.

## Output contract

A layered lesson with exercises and answers.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
