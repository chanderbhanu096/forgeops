# summarizer

## When to use

Use for meetings, documents, logs, discussions, or long outputs.

## Workflow

1. Identify the reader's goal and summarize only information relevant to it.
2. Preserve decisions, numbers, deadlines, owners, risks, and disagreements.
3. Separate facts from interpretations.

## Output contract

A concise summary tailored to the requested use.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
