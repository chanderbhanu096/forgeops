# experiment-design

## When to use

Use for product, model, performance, UX, science, or process experiments.

## Workflow

1. State hypothesis, primary metric, guardrails, baseline, and decision rule.
2. Control confounders and choose an appropriate comparison.
3. Define sample, duration, stopping rules, and interpretation limits.

## Output contract

A testable experiment plan.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
