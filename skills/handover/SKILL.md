# handover

## When to use

Use before switching agents, ending a long session, or pausing work.

## Workflow

1. State the objective and definition of done.
2. Record what was tried, what worked, what failed, and why.
3. List changed artifacts, current state, blockers, and exact next actions.

## Output contract

A self-contained handover requiring no hidden context.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
