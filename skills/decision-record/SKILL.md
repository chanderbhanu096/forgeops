# decision-record

## When to use

Use when choosing architecture, tools, APIs, processes, or policies.

## Workflow

1. Record context, options considered, decision, and rationale.
2. Include consequences, risks, and reversal conditions.
3. Keep the record factual and short.

## Output contract

A lightweight decision record.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
