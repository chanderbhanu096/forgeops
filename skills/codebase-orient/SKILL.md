# codebase-orient

## When to use

Use at the start of repository work.

## Workflow

1. Map entry points, major modules, configuration, tests, and runtime boundaries.
2. Trace the specific path related to the task instead of reading everything.
3. Record conventions and commands that affect safe changes.

## Output contract

A compact codebase map and likely change surface.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
