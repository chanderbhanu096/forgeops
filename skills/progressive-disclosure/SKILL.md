# progressive-disclosure

## When to use

Use when an answer could range from quick guidance to deep technical detail.

## Workflow

1. Lead with the smallest complete answer.
2. Put optional depth after the decision or action.
3. Do not front-load implementation detail the user did not need.

## Output contract

A layered answer with essential content first.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
