# idea-evaluator

## When to use

Use after brainstorming or when choosing among several approaches.

## Workflow

1. Define criteria such as impact, effort, risk, differentiation, learning value, and reversibility.
2. Score consistently and explain decisive tradeoffs.
3. Recommend one option and state what could change the decision.

## Output contract

A ranked decision with rationale and assumptions.

## Guardrails

- Load this skill only when it materially improves the task.
- Prefer concrete evidence over assumptions.
- Keep the result proportional to the user's requested depth.
- Do not repeat context that is already available unless it is needed for the output.
